# sena-makine-arizasi-tahmini

TRAI bootcamp final projem: AI4I 2020 veri setiyle makine arızası tahmini (kestirimci bakım). Lojistik regresyon, karar ağacı, random forest ve XGBoost denedim; veri dengesiz olduğu için accuracy yerine recall ve f1 üzerinden değerlendirdim. Üzerine öznitelik mühendisliği (sicaklik_farki ve guc değişkenleri), stratified k-fold çapraz doğrulama, GridSearchCV ile hiperparametre araması ve SHAP ile açıklanabilirlik ekledim.

Defter: makine_arizasi_tahmini.ipynb (Google Colab'da yazdım). Grafikler grafikler/ klasöründe, yazının taslağı medium_yazisi.md dosyasında.
